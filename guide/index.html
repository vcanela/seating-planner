Seating Planner

· User Guide Open App

A quick walkthrough of the five things you need to know. The whole workflow takes under two minutes the first time.

1

🗂️ Create or select a class

Click the gear icon (top-right) to open the setup panel. On the Layout tab you can rename the current class, create a new one, duplicate it, or switch between classes using the dropdown.

Each class stores its own room layout, student list, constraints, and last seating plan independently.

2

🪑 Draw the room layout

Set the number of rows and columns to match your room, then click Edit Seat Layout. The panel stays open — click or drag directly on the grid to toggle individual seats on or off. Gaps in the grid (non-available seats) are simply left untoggled.

Click Done Editing Layout when finished.

Tip: The top of the grid is always the front of the room (Board / Front of Class).
3

👩‍🎓 Add students

Switch to the Students tab. Type names separated by commas or new lines, then press Enter or click Add to List. Duplicates are skipped automatically.

The counter at the bottom shows students vs. seats — you need at least as many seats as students before you can generate a plan.

4

⚙️ Set constraints optional

On the Constraints tab, choose a constraint type and select the relevant student(s):

⬆ Sit at Front Ensures a student is placed in the front rows. ↔ Keep Separated Keeps two students away from each other.

The Flexibility bar shows how constrained the plan is overall. Many constraints reduce variation between reshuffles.

Use Hide to collapse the active constraints list — useful if students are nearby and you don't want them reading the screen.

5

🔀 Generate & refine

Close the panel and click Generate in the top bar. The planner runs 200 random arrangements and picks the one that best satisfies all constraints.

Click Reshuffle at any time to produce a new arrangement. The banner shows what percentage of seats changed — low percentages mean constraints are limiting variation.

Drag students on the grid to manually swap seats after generating.

Print: Click Print in the top bar for a clean, ink-friendly layout with no UI chrome.
💾

Import & Export

On the Import/Export tab you can save a single class or all classes as a JSON file. Share a file with a colleague or move your library to another device by importing it back — imported classes are added to your existing library without overwriting anything.

All data is stored in your browser's local storage; nothing is sent to a server.
